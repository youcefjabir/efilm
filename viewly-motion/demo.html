Quick Start

1. Kör frontendsystemet lokalt

cd /home/user/efilm/viewly-motion && npx serve .

Öppnar på http://localhost:3000

2. (Valfritt) Kör backend för real produktion

cd /home/user/efilm/backend && npm install && npm run dev

Backend på http://localhost:3001 — möjliggör video-generering via Higgsfield MCP

3. Starta ett projekt

Material → ladda upp 6–12 bostadsbilder Direction → välj Lugn / Balanserad / Dynamisk Musik → välj från biblioteket (eller ladda upp egen) Timing → HÄR HÖR DU MUSIKEN OCH SER BILDERNA SYNKRONISERADE

Video Provider

Music Analysis

Real DSP lokalt i webbläsaren

• FFT för spektralflöde (onsets)

Tech Stack

Frontend: Vanilla JS, Canvas, Web Audio API

Backend: Node.js + Express

Storage: IndexedDB (browser), PostgreSQL (optional)

Kostnad

Bara videon kostar — musik, bildanalys och timing-preview är gratis.

Exakta krediter innan produktion startar.

Export

• WebM (H.265 + Vorbis) i webbläsaren

• H.264 MP4 via server (optional)

• Aspects: 9:16, 16:9, 1:1

Workflow Time

Från bilder till production-ready: 5–15 minuter

Generering: 10–30 sekunder per shot

Arkitektur

Systemet är uppdelat i två delar: frontend (musik + preview) och backend (Higgsfield-adapter). 

Frontend (http://localhost:3000)
  ├─ Material upload
  ├─ Music selection + analysis (Web Audio API)
  ├─ Timing preview (animates stills + plays music)
  ├─ Timeline editor
  └─ WebM export

Backend (http://localhost:3001)
  ├─ Production state
  ├─ Image upload → Higgsfield
  ├─ Job dispatch (generate_video_batch)
  ├─ Job polling (jobs_wait)
  └─ Live cost lookup (get_cost)

Higgsfield MCP
  ├─ media_upload: Image storage
  ├─ generate_video_batch: Video generation
  ├─ jobs_wait: Status polling
  └─ get_cost: Live pricing
